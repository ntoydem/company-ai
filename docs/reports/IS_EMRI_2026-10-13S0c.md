## 2. Bloke: `claude-sonnet-5-5` artık `thinking: {"type": "disabled"}` kabul etmiyor

### 2.1 Gözlem (koşu sırasında)
3. soru `ANK-DEV-003` (Haiku router → `MIXED_QUERY`): belge kısmı Haiku ile cevaplandı, ardından Excel **plan** çağrısı (`LLM_MODEL_EXCEL_PLAN=claude-sonnet-5-5`) **HTTP 400** aldı; `LLMUnavailableError` → `/api/ask` 503 → eval 3 yeniden deneme → `errored: http 503 after 3 retries`. 18. soru `ANK-OPS-001` (yine MIXED) aynı yolda hata verirken koşu durduruldu.

Backend log (`llm call failed`, `error_type: LLMUnavailableError`), tam metin:
```
Error code: 400 - {'type': 'error', 'error': {'type': 'invalid_request_error', 'message':
'To turn thinking off on this model, send "thinking": {"type": "between_tools"} instead of
{"type": "disabled"}. The model does not think before responding. The short updates it writes
between tool calls come back as thinking blocks.'}}
```

### 2.2 Teşhis (6 küçük doğrudan API çağrısı, container içinden, `anthropic` SDK 1.13.0, max_tokens 64)
| Model | `disabled` | `between_tools` | `adaptive` |
|---|---|---|---|
| `claude-sonnet-5-5` | ❌ 400 "send between_tools instead of disabled" | ✅ `end_turn`, yalnız `text` bloğu, out 4 | ✅ |
| `claude-haiku-5-5` | ✅ `end_turn`, yalnız `text`, out 4 | ❌ 400 "`thinking.type.between_tools` is not supported for this model" | ✅ |

**Kök neden:** "düşünme kapalı" değeri sağlayıcıda **modele göre farklı**: Haiku 5.5 → `disabled`, Sonnet 5.5 → `between_tools`. `backend/app/services/llm/anthropic_client.py` (K-B1F) her çağrıya **tek sabit** `self._thinking = {"type": "disabled"}` gönderiyor. Haiku çağrıları (router, belge cevabı, Excel aktarım, metadata) sorunsuz; **Sonnet'e giden tek çağrı olan Excel planı her seferinde 400**. Yani bu dal + bu ayarlarla **hiçbir DATA/MIXED sorusu cevaplanamaz**; `/api/ask` DATA-miss belge hattına da düşmez (istisna 503 olarak çıkıyor, "veri yok" değil). Aynı durum canlı S1 (`LLM_PROVIDER=anthropic` + `LLM_MODEL_EXCEL_PLAN=claude-sonnet-5-5`) için de geçerli olacaktır. (D Adım 4'ün C3 koşusu 11.10'da Sonnet ile çalışmıştı: o tarihte `thinking` parametresi hiç gönderilmiyordu; K-B1F 12.10'da ekledi.)

## 3. SORU — nasıl devam edilsin? (ölçüm bu karar olmadan yapılamıyor)

**SORU 1 (önerim A):** `anthropic_client.py`'de "düşünme kapalı" değerini modele göre seçen küçük bir düzeltme onaylansın mı? Taslak: `_thinking_off(model)` → model adı `sonnet` içeriyorsa `{"type": "between_tools"}`, aksi hâlde `{"type": "disabled"}`; `ANTHROPIC_THINKING=true` davranışı (`adaptive`) aynen kalır; tek dokunuş `messages.create(..., thinking=…)` satırı + modül docstring + 2 birim testi (Sonnet → between_tools, Haiku → disabled). Prompt, şema, ayar anahtarı değişmez. Ç-16'ya göre bu emrin dışında; ayrı küçük emir (ör. S0-d) olarak ya da bu emrin kapsamına eklenerek yapılabilir. Sonra S0-c **aynen** (Haiku/Haiku + Sonnet plan + düşünme kapalı) yeniden koşulur; ortam hazır, koşu ≈ 15 dk, ≈ $0,5.
Not: canlıya geçiş (S1) da Sonnet plan modeliyle bu düzeltmeye muhtaç; `LLM_MODEL_EXCEL_PLAN` boş kaldığında (plan = Haiku) sorun yok.

Alternatifler (yalnız ayar, kod yok — ama emrin şartlarından birini bozar):
- **B)** `-e ANTHROPIC_THINKING=true` → tüm çağrılar `adaptive`. "Düşünme kapalı" şartı düşer; K-B1 §4a'daki risk (Haiku router'ın 300 token bütçesini düşünme bloğu yiyor → `router_fallback`) geri gelir; ölçüm "düşünme açık" ölçümü olur.
- **C)** `-e LLM_MODEL_EXCEL_PLAN=claude-haiku-5-5` → plan modeli Haiku. Tansu'nun Sonnet kararı (11. tur §A3) dışına çıkar; "plan modeli Sonnet çağrı sayısı" satırı 0 olur.

Karar gelene kadar hiçbir seçenek uygulanmadı.
