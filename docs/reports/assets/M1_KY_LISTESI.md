# M1 — Kendinden emin yanlış (KY) listesi, genişletilmiş K-F tanımı

**Tanım (emir madde 2):** verilen cevap kendinden emin **ve** şunlardan biri: (K1) ledger'a aykırı rakam/tarih; (K2) kural ihlali (F-8 biçim, karşılaştırma sabit cümlesi, genel bilgi vb.); (K3) proje karışması; (K4) başka projenin belgesini doğru diye sunma; (K5) eksik listeyi/cevabı tam gibi sunma. Netleştirme sorusu / F-3 listesi veren 44 cevapsız yanıt "kendinden emin" değildir; yine de K3/K4 için tarandı (liste içinde yabancı proje).
