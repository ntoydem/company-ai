## 1. Hazırlık (Adım 1)

### 1a. Komutun eval karşılığı

`make seed-demo-documents` eval ortamında **olduğu gibi kullanılamaz**. `infra/docker-compose.yml` dosyasında proje adı `name: company-ai` olarak sabit. Makefile'daki `COMPOSE` tanımında `-p` yok. Bu yüzden `make … ENV_FILE=infra/.env.eval` komutu canlı compose projesine (`company-ai-*`) gider.

Çözüm: make hedefinin içindeki iki komutu açık proje adıyla çalıştırmak. Komutların kendisi değişmedi:

```bash
EC="docker compose -p company-ai-eval --project-directory . -f infra/docker-compose.yml --env-file infra/.env.eval"
$EC run --rm -T backend python -m app.cli seed-demo-documents                 # make seed-demo-documents, 1. satır
$EC run --rm -T backend python -m app.cli wait-for-documents --timeout 600    # make seed-demo-documents, 2. satır
$EC run --rm -T backend python -m scripts.validate_ocr --all                  # make validate-ocr ARGS=--all
```

SELECT'ler doğrudan eval postgres container'ında çalıştırıldı (`docker exec company-ai-eval-postgres-1 … psql`). Her sorgu `current_database()` = `company_ai_eval` olarak döndü. Canlı tarafta yalnız karşılaştırma için SELECT yapıldı (`company-ai-postgres-1`).

**Güvenlik kontrolleri:**
- `$EC config` çıktısında proje adı `company-ai-eval`. postgres `data-eval/postgres` klasörünü bağlıyor; backend ve ocr-worker `data-eval/documents` (backend ayrıca `excel` ve `app-data`) klasörlerini bağlıyor. `DATABASE_URL` her ikisinde de `postgres:5432/company_ai_eval`.
- Compose'da `env_file: .env` var, yani canlı `.env` eval container'larına da yükleniyor. Ancak `DATABASE_URL` ve volume yolları `environment` ve `.env.eval` interpolasyonuyla eval değerlerini alıyor. Uygulama `DATA_ROOT` ya da `POSTGRES_DB` değişkenini okumuyor; yalnız `DATABASE_URL` ve `APP_DATA_DIR` değişkenlerini kullanıyor.
- `postgres` host adı yalnız `company-ai-eval_default` ağında çözülüyor.
- Backend entrypoint'i `alembic upgrade head` çalıştırıyor. Şemanın başı 0016 ve eval DB de 0016'da; loglarda `Running upgrade` satırı 0.
- Seed ve OCR yolunda LLM çağrısı yok: `app.cli seed-demo-documents` → `ensure_demo_documents`, ocr-worker → ocrmypdf + PyMuPDF.
